# Оркестратор Risk Manager

> Защитник счёта в реальном времени: он следит за состоянием счёта и **закрывает всё** в тот момент, когда нарушается любой лимит риска — просадка, дневной убыток, уровень маржи или число позиций.

!!! warning "Только для демонстрации — не готово к продакшену"
    Этот оркестратор показывает идею стратегии и стоящие за ней вызовы API. Реальное развёртывание требует всеобъемлющего риск-менеджмента, обработки ошибок, логирования, мониторинга и обширного тестирования. Запускайте его только на **демо-счёте**.

→ Исходник: [`examples/4_orchestrators/14_risk_manager.py`](https://github.com/MetaRPC/PyMT5/blob/main/examples/4_orchestrators/14_risk_manager.py)

---

## Что он делает

Фиксирует начальный баланс, затем отслеживает **все** открытые позиции в реальном времени. Если пересекается любой настроенный порог, он закрывает каждую позицию сразу, чтобы защитить счёт от неконтролируемой просадки, маржин-коллов и избыточного плеча. В отличие от остальных оркестраторов, он смотрит на счёт в целом, а не управляет одной стратегией.

## Как это работает

1. Открывает 2 тестовые позиции (BUY + SELL, по `0.01` лота) для демонстрации.
2. Записывает начальный баланс счёта.
3. Стримит P&L для всех позиций через `stream_position_profits()`.
4. Каждые ~10 секунд печатает: текущую просадку, дневной P&L %, уровень маржи, число открытых позиций, суммарный P&L.
5. **Автоматическая защита** — закрывает все позиции, если нарушен любой лимит:
   - просадка > `max_drawdown_percent`;
   - дневной убыток > `max_daily_loss_percent`;
   - уровень маржи < `min_margin_level`;
   - число открытых позиций > `max_positions`.
6. Логирует каждое нарушение и закрытие, затем печатает итоговый отчёт о рисках. Тестовые позиции очищаются на выходе.

## Параметры

Конструктор принимает `service` и необязательный `RiskLimits`:

```python
RiskManagerOrchestrator(service, limits: RiskLimits | None = None)
```

Поля `RiskLimits`:

| Поле | Тип | По умолчанию | Значение |
| --- | --- | --- | --- |
| `max_drawdown_percent` | `float` | `10.0` | Закрыть всё, если средства (equity) упадут на столько от начального баланса. |
| `max_daily_loss_percent` | `float` | `5.0` | Закрыть всё, если сегодняшний убыток превысит это значение. |
| `min_margin_level` | `float` | `150.0` | Закрыть всё, если уровень маржи упадёт ниже этого (%). |
| `max_positions` | `int` | `10` | Закрыть всё, если число открытых позиций превысит это. |
| `max_risk_per_trade_percent` | `float` | `2.0` | Зарезервировано для будущего расчёта объёма на сделку. |

`await start(duration_minutes=3.0)` запускает мониторинг. (Пункт меню вызывает обёртку модуля `run_risk_manager_example()`.)

## Примеры сценариев

- **Просадка:** старт $10,000, лимит 10%. Средства (equity) → $8,900 (−11%) → закрыть все 3 позиции.
- **Дневной убыток:** лимит 5% ($500). Сегодня −$550 (−5.5%) → закрыть всё.
- **Предотвращение маржин-колла:** уровень маржи 140% < 150% → закрыть, чтобы освободить маржу.
- **Лимит позиций:** 12 открытых > 10 → закрыть всё.

## Запуск

```bash
cd examples
python main.py risk          # или: riskmanager, или пункт меню [14]
```

## Минимальное использование

```python
import asyncio
from pymt5.mt5_service import MT5Service
from demo_helpers import load_settings, create_and_connect_mt5
# RiskLimits находится в модуле оркестратора (14_risk_manager.py)

async def main():
    config = load_settings()
    account = await create_and_connect_mt5(config)
    service = MT5Service(account)

    limits = RiskLimits(
        max_drawdown_percent=15.0,   # больше запаса
        max_daily_loss_percent=3.0,  # строже дневной лимит
        min_margin_level=200.0,      # выше буфер маржи
        max_positions=5,
    )
    orch = RiskManagerOrchestrator(service, limits=limits)
    await orch.start(duration_minutes=3.0)

    await account.disconnect()

asyncio.run(main())
```

## Используемые методы API

- **MT5Service:** `stream_position_profits()` (основной), `get_opened_orders()`, `get_account_summary()`, `close_order()` (массовое закрытие при нарушении, через `OrderCloseRequest`).
- **MT5Sugar:** `buy_market()` / `sell_market()` — используются только демо-помощником, который открывает тестовые позиции (сам оркестратор принимает только `service`).

## Примечания

- Это защита всего счёта — она действует на **каждую** открытую позицию, а не только на те, что открыл сам (кроме демо-очистки собственных тестовых сделок).
- Пороги проверяются при каждом обновлении стрима, поэтому нарушение запускает почти мгновенное закрытие.
- Сочетайте его с любым другим оркестратором в вашем собственном раннере, чтобы добавить страховочную сетку.
