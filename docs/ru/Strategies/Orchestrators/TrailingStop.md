# Оркестратор Trailing Stop

> Автоматическое управление трейлинг-стоп-лоссом с интеллектуальным автозакрытием. Открывает тестовые позиции, наблюдает за ними в реальном времени и перемещает стоп-лосс ближе к цене, фиксируя прибыль, — одновременно закрывая позиции, которые зависают или уходят в убыток.

!!! warning "Только для демонстрации — не готово к продакшену"
    Этот оркестратор показывает идею стратегии и стоящие за ней вызовы API. Реальное развёртывание требует правильного расчёта объёма позиции, контроля проскальзывания, логирования, мониторинга и обширного тестирования. Запускайте его только на **демо-счёте**.

→ Исходник: [`examples/4_orchestrators/11_trailing_stop.py`](https://github.com/MetaRPC/PyMT5/blob/main/examples/4_orchestrators/11_trailing_stop.py)

---

## Что он делает

Держит защитный стоп-лосс трейлингом за прибыльной позицией, так что, когда цена разворачивается, вы сохраняете бóльшую часть выигрыша вместо того, чтобы отдать всё обратно. Он также обеспечивает два защитных выхода: жёсткий лимит убытка и таймаут «не сработало вовремя».

Он управляет **только теми позициями, которые открыл сам** (отслеживаемыми по тикету), поэтому оставляет остальную часть вашего счёта нетронутой.

## Как это работает

1. Автоматически открывает 2 тестовые позиции (BUY + SELL, по `0.01` лота каждая).
2. Стримит для них живой P&L через `stream_position_profits()` каждую секунду.
3. **Проверки автозакрытия** (при каждом обновлении):
   - убыток превышает `max_loss_pips` → немедленно закрыть;
   - прибыль не достигла `activation_profit_pips` в течение `max_wait_minutes` → закрыть.
4. **Активация трейлинга** (прибыль ≥ `activation_profit_pips`):
   - стоп начинает следовать за ценой на расстоянии `trail_distance_pips` позади неё;
   - стоп всегда движется только в благоприятном направлении (никогда не ослабляется).
5. Печатает подробный статус с таймерами обратного отсчёта каждые 30 секунд.
6. Работает в течение `duration_minutes`, затем печатает сводку с суммарным P&L.

## Параметры

| Параметр | Тип | По умолчанию | Значение |
| --- | --- | --- | --- |
| `service` | `MT5Service` | — | Типизированный фасад для стриминга, котировок и `modify_order`. |
| `sugar` | `MT5Sugar` | — | Высокоуровневые помощники (`buy_market`, `close_position`, `get_symbol_info`). |
| `trail_distance_pips` | `float` | `20.0` | Расстояние между ценой и стопом после активации трейлинга. |
| `activation_profit_pips` | `float` | `30.0` | Минимальная прибыль, прежде чем трейлинг включится. |
| `update_interval_ms` | `int` | `1000` | Как часто стрим позиции отправляет данные (мс). |
| `symbols` | `list \| None` | `None` | Ограничить этими символами (`None` = все). |
| `dry_run` | `bool` | `False` | Логировать предполагаемые действия без изменения ордеров. |
| `max_wait_minutes` | `float` | `2.0` | Автозакрытие, если трейлинг не активируется за это время. |
| `max_loss_pips` | `float` | `50.0` | Автозакрытие, как только убыток превысит это значение. |
| `managed_tickets` | `list \| None` | `None` | Управлять только этими тикетами (`None` = каждая позиция). |

`await start(duration_minutes=3.0, cancellation_event=None)` запускает цикл.

## Пример сценария

BUY EURUSD по 1.2000 — трейлинг 20 пипсов, активация 30 пипсов, макс. убыток 50 пипсов, макс. ожидание 2 мин.

- **Прибыльно:** цена → 1.2040 (+40п) активирует трейлинг, SL установлен на 1.2020. Цена → 1.2060 (+60п), SL → 1.2040. Цена разворачивается до 1.2038 → срабатывает SL на 1.2040 = **зафиксировано +40 пипсов**.
- **Без активации:** цена колеблется ±10п в течение 2 минут (так и не достигает +30п) → автозакрытие примерно в точке безубытка.
- **Крупный убыток:** цена падает до 1.1950 (−50п) → автозакрытие на лимите убытка.

## Минимальное использование

```python
import asyncio
from pymt5.mt5_service import MT5Service
from pymt5.mt5_sugar import MT5Sugar
from demo_helpers import load_settings, create_and_connect_mt5

async def main():
    config = load_settings()
    account = await create_and_connect_mt5(config)
    service = MT5Service(account)
    sugar = MT5Sugar(service, default_symbol=config["test_symbol"])

    orch = TrailingStopOrchestrator(
        service, sugar,
        trail_distance_pips=20.0,
        activation_profit_pips=30.0,
        max_loss_pips=50.0,
        max_wait_minutes=2.0,
    )
    await orch.start(duration_minutes=3.0)

    await account.disconnect()

asyncio.run(main())
```

## Используемые методы API

- **MT5Service:** `stream_position_profits()` (основной), `get_opened_orders()`, `modify_order()`, `get_symbol_tick()`.
- **MT5Sugar:** `buy_market()`, `sell_market()`, `close_position()`, `get_symbol_info()`.

## Примечания

- Перемещает стоп **только** в благоприятном направлении — он фиксирует прибыль, никогда не расширяет риск.
- Размер пипса выводится для каждого символа: на символах с 3/5 знаками 1 пипс = 10 пунктов.
- Стриминг (1 с) удерживает низкую задержку; `Ctrl+C` запускает корректное завершение через событие отмены.
- `dry_run=True` логирует каждое предполагаемое изменение/закрытие, не затрагивая счёт, — используйте это, чтобы безопасно наблюдать за логикой.
