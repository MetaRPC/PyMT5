# MT5Service - Методы глубины рынка (API среднего уровня)

## ⚠️ Важно: Прочитайте сначала это

**MT5Service - это архитектурный слой** между высокоуровневым (Sugar) и низкоуровневым (Account) API.

### Понимание 3 методов:

| Метод | Ценность прямого использования | Архитектурная роль |
|--------|------------------|-------------------|
| `get_market_depth()` | ✅ **ВЫСОКАЯ** - Преобразует protobuf repeated → dataclass List[BookInfo] | ✅ Используется Sugar |
| `subscribe_market_depth()` | ✅ **СРЕДНЯЯ** - Распаковывает `data.opened_successfully` из protobuf | ✅ Используется Sugar |
| `unsubscribe_market_depth()` | ✅ **СРЕДНЯЯ** - Распаковывает `data.closed_successfully` из protobuf | ✅ Используется Sugar |

### Что это значит:

**Архитектура (3 слоя):**
```
MT5Sugar (ВЫСОКИЙ)     →  service.get_market_depth()      ← Sugar использует методы Service
MT5Service (СРЕДНИЙ)   →  account.market_book_get()       ← Service распаковывает protobuf + создаёт dataclasses
MT5Account (НИЗКИЙ)    →  gRPC-вызов → protobuf-объекты Data
```

**Ключевое отличие от методов Account:**

- ✅ **ВСЕ 3 метода имеют ценность** - MT5Account возвращает protobuf-объекты Data, которые требуют распаковки
- ✅ **Распаковка protobuf** - Service преобразует repeated-поле `data.mql_book_infos` в список Python
- ✅ **Создание dataclass** - dataclass `BookInfo` вместо сообщений protobuf `MrpcMqlBookInfo`
- ✅ **Более чистый API** - Прямой возврат bool/list вместо ручного извлечения из структуры Data

**Для прямого использования MT5Service:**

- ✅ **Используйте все 3 метода** - все они добавляют ценность через распаковку protobuf
- ✅ **Высокая ценность**: `get_market_depth()` - преобразует repeated-поле protobuf в чистый List[BookInfo]
- ✅ **Средняя ценность**: методы подписки - распаковывают bool из структуры Data

**Для пользователей MT5Sugar:**

- ✅ Все методы работают безупречно - слой выполняет свою архитектурную задачу

---

**Слой API:** **СРЕДНИЙ УРОВЕНЬ** - обёртки над MT5Account с нативными типами Python

**Реализация:**

Эти методы реализованы в `src/pymt5/mt5_service.py`, который оборачивает низкоуровневый API `package/MetaRpcMT5/helpers/mt5_account.py` с преобразованием в dataclass для записей стакана ордеров.

**Файлы примеров:**

- `examples/2_service/04_service_demo.py` - исчерпывающий демо-пример всех методов MT5Service, включая глубину рынка (STEP 4)

## Зачем эти методы существуют

### Реальная ценность: Распаковка protobuf + преобразование в dataclass

**ВСЕ 3 метода добавляют реальную ценность**, потому что MT5Account возвращает protobuf-объекты Data, требующие ручной распаковки:

**Проблема с MT5Account** (низкий уровень):

```python
# MT5Account возвращает protobuf-объекты Data — нужна ручная распаковка
# Подписка
add_data = await account.market_book_add("EURUSD", None, None)
success = add_data.opened_successfully  # ← Ручное извлечение из protobuf-обёртки

# Получаем DOM
dom_data = await account.market_book_get("EURUSD", None, None)
books = dom_data.mql_book_infos  # ← protobuf repeated-поле (не список Python!)
for book in books:
    # book — это protobuf MrpcMqlBookInfo, а не чистый dataclass
    print(f"{book.type}: {book.price} x {book.volume}")

# Отписка
release_data = await account.market_book_release("EURUSD", None, None)
success = release_data.closed_successfully  # ← Снова ручное извлечение
```

**Решение с MT5Service** (средний уровень):

```python
# Service распаковывает protobuf автоматически — чистые типы Python
# Подписка
success = await service.subscribe_market_depth("EURUSD")  # ← Уже bool, а не Data!

# Получаем DOM — возвращает dataclass List[BookInfo]
books = await service.get_market_depth("EURUSD")  # ← Список Python, а не protobuf repeated!
for book in books:
    # Чистый dataclass с подсказками типов
    print(f"{book.type}: {book.price} x {book.volume_real}")

# Отписка
success = await service.unsubscribe_market_depth("EURUSD")  # ← Уже bool!
```

**Что предоставляет MT5Service:**

1. **Распаковка protobuf** (все 3 метода):

   - MT5Account: `return res.data` (protobuf-объекты Data)
   - MT5Service: `return data.opened_successfully` / `data.closed_successfully` или `List[BookInfo]` (нативные типы Python)

2. **Преобразование в dataclass** (1 метод):

   - `get_market_depth()`: Преобразует protobuf repeated `MrpcMqlBookInfo` → чистый dataclass `List[BookInfo]`

3. **Более чистый API**:

   - Нет нужды вручную извлекать `.success` из обёрток Data
   - Нет нужды работать с protobuf repeated-полями
   - Подсказки типов для автодополнения в IDE

**Архитектурное назначение:**

- ✅ **MT5Sugar** использует эти методы для поддержания слоистой архитектуры (Sugar → Service → Account)
- ✅ **Прямые пользователи** тоже выигрывают - все методы добавляют ценность через распаковку и преобразование

## Ключевые концепции

### Что такое глубина рынка (DOM)?

**Глубина рынка** (Depth of Market, DOM, стакан ордеров) показывает:
- **Уровни Bid**: Ордера на покупку, ожидающие на разных ценовых уровнях
- **Уровни Ask**: Ордера на продажу, ожидающие на разных ценовых уровнях
- **Объём**: Сколько объёма доступно на каждом ценовом уровне

### Как это работает:

1. **Подпишитесь** на символ (`subscribe_market_depth`)
2. **Получайте снимки** по мере необходимости (`get_market_depth`)
3. **Отпишитесь** по завершении (`unsubscribe_market_depth`)

### Важные примечания:

- Вы ОБЯЗАНЫ подписаться перед вызовом `get_market_depth()`
- Всегда отписывайтесь по завершении, чтобы освободить ресурсы терминала
- Брокеры могут ограничивать число одновременных подписок на DOM (обычно 5-10 символов)
- Не все символы поддерживают DOM (уточните у брокера)

## ➕ Dataclass (DTO)

### BookInfo

```python
@dataclass
class BookInfo:
    """Single Depth of Market (DOM) price level entry."""
    type: Any           # SELL (ask) или BUY (bid)
    price: float        # Ценовой уровень
    volume: int         # Объём в лотах (целое число)
    volume_real: float  # Объём с десятичной точностью
```

**Пояснение полей:**

- **type**: `1` = BUY (уровень bid), `2` = SELL (уровень ask)
- **price**: Ценовой уровень (например, 1.08550 для EURUSD)
- **volume**: Объём в целых лотах (например, 5 лотов)
- **volume_real**: Объём с десятичными (например, 5.75 лота)

**Порядок стакана:**

- Уровни Bid: отсортированы от наибольшего к наименьшему (лучший bid первым)
- Уровни Ask: отсортированы от наименьшего к наибольшему (лучший ask первым)

## Сигнатуры методов

### 1) subscribe_market_depth

```python
async def subscribe_market_depth(
    self,
    symbol: str,
    deadline: Optional[datetime] = None,
    cancellation_event: Optional[Any] = None,
) -> bool
```

**Подписаться на обновления глубины рынка (DOM).**

**Аргументы:**

- `symbol`: Имя символа для подписки (например, "EURUSD", "BTCUSD")

**Возвращает:** `bool` - `True`, если подписка успешна, иначе `False`

**Технические детали:** Низкий уровень возвращает MarketBookAddData с обёрткой `data.opened_successfully`. Этот метод автоматически извлекает bool.

**Важно:**

- Требуется перед вызовом `get_market_depth()` для получения снимков DOM
- Терминал поддерживает подписку - вызывайте `unsubscribe_market_depth()` по завершении
- Брокеры ограничивают число одновременных подписок (обычно максимум 5-10 символов)

**Шаблон использования:**

```python
# Сначала подписка
if await service.subscribe_market_depth("EURUSD"):
    # Теперь можно получать данные DOM
    books = await service.get_market_depth("EURUSD")
```

### 2) unsubscribe_market_depth

```python
async def unsubscribe_market_depth(
    self,
    symbol: str,
    deadline: Optional[datetime] = None,
    cancellation_event: Optional[Any] = None,
) -> bool
```

**Отписаться от обновлений DOM.**

**Аргументы:**

- `symbol`: Имя символа для отписки

**Возвращает:** `bool` - `True`, если отписка успешна, иначе `False`

**Технические детали:** Низкий уровень возвращает MarketBookReleaseData с обёрткой `data.closed_successfully`. Этот метод автоматически извлекает bool.

**Важно:**

- Всегда отписывайтесь по завершении, чтобы освободить ресурсы терминала
- Брокеры могут ограничивать число одновременных подписок на DOM
- Неотписка может помешать подписке на другие символы

**Шаблон использования:**

```python
try:
    # Работаем с DOM
    books = await service.get_market_depth("EURUSD")
    # ... обработка данных ...
finally:
    # Всегда очистка
    await service.unsubscribe_market_depth("EURUSD")
```

### 3) get_market_depth

```python
async def get_market_depth(
    self,
    symbol: str,
    deadline: Optional[datetime] = None,
    cancellation_event: Optional[Any] = None,
) -> List[BookInfo]
```

**Получить текущий снимок DOM (стакан ордеров).**

**Аргументы:**

- `symbol`: Имя символа

**Возвращает:** `List[BookInfo]` - Список записей стакана ордеров (уровни bid и ask)

**Технические детали:** Низкий уровень возвращает MarketBookGetData с `data.mql_book_infos` (repeated MrpcMqlBookInfo protobuf). Эта обёртка распаковывает каждый MrpcMqlBookInfo в dataclass BookInfo.

**Важно:**

- Требует предварительной подписки `subscribe_market_depth()`
- Возвращает текущий снимок (не стриминг)
- BookInfo.type: `1` = BUY (bid), `2` = SELL (ask)

**Структура стакана:**

```
SELL levels (asks) - sorted low to high:
  1.08570 x 10.0 lots (type=2)
  1.08560 x 15.5 lots (type=2)
  1.08550 x 8.0 lots  (type=2)  <- Best ask
--------------------
  1.08540 x 12.0 lots (type=1) <- Best bid
  1.08530 x 20.0 lots (type=1)
  1.08520 x 5.0 lots  (type=1)
BUY levels (bids) - sorted high to low
```

## 🔗 Примеры использования

### Пример 1: Базовая подписка и получение DOM

```python
from pymt5 import MT5Service

async def get_dom(service: MT5Service, symbol: str):
    """Basic DOM usage pattern."""

    try:
        # Шаг 1: Подписка
        success = await service.subscribe_market_depth(symbol)
        if not success:
            print(f"Failed to subscribe to {symbol} DOM")
            return

        print(f"Subscribed to {symbol} DOM")

        # Шаг 2: Получаем данные DOM
        books = await service.get_market_depth(symbol)

        print(f"\nMarket Depth for {symbol}:")
        print("-" * 60)

        # Разделяем bid и ask
        bids = [b for b in books if b.type == 1]
        asks = [b for b in books if b.type == 2]

        # Отображаем ask (в обратном порядке, чтобы лучший ask был последним)
        print("\nASKS (Sell orders):")
        for book in reversed(asks):
            print(f"  {book.price:.5f} x {book.volume_real:.2f} lots")

        print("\n" + "=" * 60)

        # Отображаем bid
        print("\nBIDS (Buy orders):")
        for book in bids:
            print(f"  {book.price:.5f} x {book.volume_real:.2f} lots")

    finally:
        # Шаг 3: Всегда отписываемся
        await service.unsubscribe_market_depth(symbol)
        print(f"\nUnsubscribed from {symbol} DOM")
```

### Пример 2: Получение лучших Bid и Ask

```python
async def get_best_prices(service: MT5Service, symbol: str):
    """Get best bid and ask from DOM."""

    try:
        # Подписка
        if not await service.subscribe_market_depth(symbol):
            return None, None

        # Получаем DOM
        books = await service.get_market_depth(symbol)

        # Разделяем bid и ask
        bids = [b for b in books if b.type == 1]
        asks = [b for b in books if b.type == 2]

        # Лучший bid = наибольшая цена bid (первый в отсортированном списке)
        best_bid = bids[0] if bids else None

        # Лучший ask = наименьшая цена ask (первый в отсортированном списке)
        best_ask = asks[0] if asks else None

        if best_bid and best_ask:
            print(f"{symbol}:")
            print(f"  Best Bid: {best_bid.price:.5f} ({best_bid.volume_real:.2f} lots)")
            print(f"  Best Ask: {best_ask.price:.5f} ({best_ask.volume_real:.2f} lots)")
            print(f"  Spread: {(best_ask.price - best_bid.price):.5f}")

            return best_bid, best_ask

    finally:
        await service.unsubscribe_market_depth(symbol)

    return None, None
```

### Пример 3: Расчёт суммарного объёма на каждой стороне

```python
async def analyze_dom_liquidity(service: MT5Service, symbol: str):
    """Analyze total bid/ask volume in DOM."""

    try:
        await service.subscribe_market_depth(symbol)
        books = await service.get_market_depth(symbol)

        # Считаем суммы
        total_bid_volume = sum(b.volume_real for b in books if b.type == 1)
        total_ask_volume = sum(b.volume_real for b in books if b.type == 2)

        bid_count = len([b for b in books if b.type == 1])
        ask_count = len([b for b in books if b.type == 2])

        print(f"{symbol} DOM Liquidity:")
        print(f"  Bid side: {total_bid_volume:.2f} lots across {bid_count} levels")
        print(f"  Ask side: {total_ask_volume:.2f} lots across {ask_count} levels")
        print(f"  Bid/Ask ratio: {total_bid_volume / total_ask_volume:.2f}")

        # Анализ дисбаланса
        if total_bid_volume > total_ask_volume * 1.5:
            print("  Status: Strong buying pressure")
        elif total_ask_volume > total_bid_volume * 1.5:
            print("  Status: Strong selling pressure")
        else:
            print("  Status: Balanced")

    finally:
        await service.unsubscribe_market_depth(symbol)
```

### Пример 4: Отображение таблицы DOM

```python
async def display_dom_table(service: MT5Service, symbol: str, levels: int = 5):
    """Display DOM as a formatted table."""

    try:
        await service.subscribe_market_depth(symbol)
        books = await service.get_market_depth(symbol)

        bids = [b for b in books if b.type == 1][:levels]
        asks = [b for b in books if b.type == 2][:levels]

        print(f"\n{symbol} - Market Depth (Top {levels} levels)")
        print("=" * 70)
        print(f"{'BID Volume':<15} {'BID Price':<15} {'ASK Price':<15} {'ASK Volume':<15}")
        print("-" * 70)

        # Разворачиваем ask, чтобы лучший ask был внизу
        asks_reversed = list(reversed(asks))

        max_levels = max(len(bids), len(asks_reversed))

        for i in range(max_levels):
            bid_vol = f"{bids[i].volume_real:.2f}" if i < len(bids) else ""
            bid_price = f"{bids[i].price:.5f}" if i < len(bids) else ""
            ask_price = f"{asks_reversed[i].price:.5f}" if i < len(asks_reversed) else ""
            ask_vol = f"{asks_reversed[i].volume_real:.2f}" if i < len(asks_reversed) else ""

            print(f"{bid_vol:<15} {bid_price:<15} {ask_price:<15} {ask_vol:<15}")

        print("=" * 70)

    finally:
        await service.unsubscribe_market_depth(symbol)
```

### Пример 5: Мониторинг изменений DOM

```python
import asyncio

async def monitor_dom_changes(
    service: MT5Service,
    symbol: str,
    interval_seconds: int = 1,
    duration_seconds: int = 60
):
    """Monitor DOM changes over time."""

    try:
        # Подписка
        if not await service.subscribe_market_depth(symbol):
            print(f"Failed to subscribe to {symbol}")
            return

        print(f"Monitoring {symbol} DOM for {duration_seconds} seconds...")

        start_time = asyncio.get_event_loop().time()

        while True:
            elapsed = asyncio.get_event_loop().time() - start_time
            if elapsed >= duration_seconds:
                break

            # Получаем текущий DOM
            books = await service.get_market_depth(symbol)

            bids = [b for b in books if b.type == 1]
            asks = [b for b in books if b.type == 2]

            if bids and asks:
                best_bid = bids[0]
                best_ask = asks[0]

                print(f"[{elapsed:.1f}s] Bid: {best_bid.price:.5f} ({best_bid.volume_real:.2f}) | "
                      f"Ask: {best_ask.price:.5f} ({best_ask.volume_real:.2f}) | "
                      f"Spread: {(best_ask.price - best_bid.price):.5f}")

            await asyncio.sleep(interval_seconds)

    finally:
        await service.unsubscribe_market_depth(symbol)
        print(f"\nStopped monitoring {symbol}")
```

### Пример 6: DOM для нескольких символов

```python
async def monitor_multiple_symbols(service: MT5Service, symbols: list):
    """Monitor DOM for multiple symbols (respecting broker limits)."""

    subscribed = []

    try:
        # Подписываемся на все символы
        for symbol in symbols:
            success = await service.subscribe_market_depth(symbol)
            if success:
                subscribed.append(symbol)
                print(f"Subscribed: {symbol}")
            else:
                print(f"Failed: {symbol} (broker limit reached?)")

        print(f"\nSuccessfully subscribed to {len(subscribed)} symbols")

        # Получаем DOM для всех символов с подпиской
        for symbol in subscribed:
            books = await service.get_market_depth(symbol)

            bids = [b for b in books if b.type == 1]
            asks = [b for b in books if b.type == 2]

            if bids and asks:
                print(f"\n{symbol}:")
                print(f"  Best Bid: {bids[0].price:.5f} x {bids[0].volume_real:.2f}")
                print(f"  Best Ask: {asks[0].price:.5f} x {asks[0].volume_real:.2f}")
                print(f"  Total levels: {len(bids)} bids, {len(asks)} asks")

    finally:
        # Отписываемся от всех
        for symbol in subscribed:
            await service.unsubscribe_market_depth(symbol)
            print(f"Unsubscribed: {symbol}")
```

### Пример 7: Поиск крупных ордеров

```python
async def find_large_orders(
    service: MT5Service,
    symbol: str,
    min_volume: float = 10.0
):
    """Find large orders in DOM (potential resistance/support)."""

    try:
        await service.subscribe_market_depth(symbol)
        books = await service.get_market_depth(symbol)

        # Находим крупные ордера
        large_bids = [b for b in books if b.type == 1 and b.volume_real >= min_volume]
        large_asks = [b for b in books if b.type == 2 and b.volume_real >= min_volume]

        print(f"\n{symbol} - Large Orders (>= {min_volume} lots):")
        print("=" * 60)

        if large_bids:
            print(f"\nLarge BID orders (potential support):")
            for book in large_bids:
                print(f"  {book.price:.5f} x {book.volume_real:.2f} lots")

        if large_asks:
            print(f"\nLarge ASK orders (potential resistance):")
            for book in large_asks:
                print(f"  {book.price:.5f} x {book.volume_real:.2f} lots")

        if not large_bids and not large_asks:
            print(f"\nNo large orders found (min: {min_volume} lots)")

    finally:
        await service.unsubscribe_market_depth(symbol)
```

## Когда какой метод использовать

### Используйте subscribe_market_depth()

**Используйте, когда:**

- Начинаете мониторинг DOM для символа
- Нужно получать обновления стакана ордеров
- Перед вызовом `get_market_depth()`

**Важно:**

- Всегда вызывайте ПЕРЕД `get_market_depth()`
- Проверяйте возвращаемое значение (False = подписка не удалась)

**Пример:**

```python
if await service.subscribe_market_depth("EURUSD"):
    # Теперь можно получать данные DOM
    pass
```

---

### Используйте get_market_depth()

**Используйте, когда:**

- Нужен текущий снимок стакана ордеров
- Анализируете рыночную ликвидность
- Находите лучшие цены bid/ask
- Ищете крупные ордера

**Важно:**

- Требует предварительной подписки
- Возвращает снимок (не стриминг)
- Вызывайте повторно для мониторинга

**Пример:**

```python
books = await service.get_market_depth("EURUSD")
best_bid = [b for b in books if b.type == 1][0]
```

---

### Используйте unsubscribe_market_depth()

**Используйте, когда:**

- Завершили мониторинг символа
- Освобождаете ресурсы
- Хотите подписаться на другой символ

**Важно:**

- ВСЕГДА вызывайте по завершении
- Освобождайте слот подписки для других символов
- Используйте в блоке `finally` для гарантированной очистки

**Пример:**

```python
try:
    await service.subscribe_market_depth("EURUSD")
    # ... работаем с DOM ...
finally:
    await service.unsubscribe_market_depth("EURUSD")
```

---

## Рекомендации

1. **Всегда отписывайтесь** - Используйте `try/finally` для гарантированной очистки
2. **Проверяйте лимиты подписок** - Брокеры обычно разрешают 5-10 одновременных подписок
3. **Проверяйте возвращаемые значения** - `subscribe_market_depth()` возвращает False при неудаче
4. **Не все символы поддерживают DOM** - Уточните у вашего брокера
5. **DOM - это снимок** - Вызывайте `get_market_depth()` повторно для мониторинга
6. **Используйте шаблон контекстного менеджера** - Обеспечивает корректную очистку

**Пример шаблона:**

```python
async def with_dom(service, symbol):
    try:
        if not await service.subscribe_market_depth(symbol):
            return
        # Работаем с DOM
        books = await service.get_market_depth(symbol)
        # ... обработка ...
    finally:
        await service.unsubscribe_market_depth(symbol)
```

---

## Типичные ошибки

1. **Забыть подписаться** - `get_market_depth()` завершится неудачей без подписки
2. **Не отписаться** - Тратит ресурсы, может помешать другим подпискам
3. **Превышение лимитов брокера** - Большинство брокеров ограничивают число одновременных подписок на DOM
4. **Предположение, что все символы поддерживают DOM** - Не все символы имеют данные глубины рынка

## Итог

### Оценка реальной ценности

**ВСЕ 3 метода добавляют реальную ценность** через распаковку protobuf и преобразование в dataclass:

| Метод | Уровень ценности | Что он делает |
|--------|-------------|--------------|
| `get_market_depth()` | ✅ **ВЫСОКАЯ** | Преобразует protobuf repeated `MrpcMqlBookInfo` → чистый dataclass `List[BookInfo]` |
| `subscribe_market_depth()` | ✅ **СРЕДНЯЯ** | Распаковывает `data.opened_successfully` из protobuf `MarketBookAddData` → bool |
| `unsubscribe_market_depth()` | ✅ **СРЕДНЯЯ** | Распаковывает `data.closed_successfully` из protobuf `MarketBookReleaseData` → bool |

**Почему эти методы имеют ценность:**

MT5Account возвращает protobuf-объекты Data:
```python
# Низкий уровень возвращает:
add_data: MarketBookAddData = await account.market_book_add(...)
dom_data: MarketBookGetData = await account.market_book_get(...)
release_data: MarketBookReleaseData = await account.market_book_release(...)
```

MT5Service распаковывает в нативные типы Python:
```python
# Средний уровень возвращает:
success: bool = await service.subscribe_market_depth(...)           # Распаковывает data.opened_successfully
books: List[BookInfo] = await service.get_market_depth(...)         # Распаковывает + преобразует data.mql_book_infos
success: bool = await service.unsubscribe_market_depth(...)         # Распаковывает data.closed_successfully
```

**Ключевые преимущества:**

1. **Распаковка protobuf** - Нет нужды вручную перебирать `.mql_book_infos`
2. **Преобразование в dataclass** - dataclass `BookInfo` вместо сообщений protobuf `MrpcMqlBookInfo`
3. **Чистые типы Python** - `bool` и `List[BookInfo]` вместо обёрток Data
4. **Подсказки типов** - Полная поддержка автодополнения в IDE
5. **Проще в использовании** - Знание protobuf не требуется

**Лучшие практики:**

- Всегда используйте `try/finally` для гарантированной очистки
- Проверяйте возвращаемые значения подписки
- Соблюдайте лимиты подписок брокера (обычно 5-10 символов)
- Не все символы поддерживают DOM - проверяйте у брокера

**Итог:**

- ✅ **Для прямых пользователей**: Все 3 метода добавляют ценность - используйте их для более чистого API
- ✅ **Для пользователей Sugar**: Методы идеально выполняют архитектурную задачу
- ✅ **vs MT5Account**: Значительное улучшение через распаковку и преобразование в dataclass
