# ✅ MT5Service - Методы счёта (API среднего уровня)

## Важно: Прочитайте сначала это

**MT5Service - это архитектурный слой** между высокоуровневым (Sugar) и низкоуровневым (Account) API.

### Понимание 4 методов:

| Метод | Ценность прямого использования | Архитектурная роль |
|--------|------------------|-------------------|
| `get_account_summary()` | **ВЫСОКАЯ** - Агрегирует 14 свойств + преобразование datetime | Используется Sugar |
| `get_account_double()` | **НЕТ** - Просто вызывает `account.account_info_double()` | Используется Sugar |
| `get_account_integer()` | **НЕТ** - Просто вызывает `account.account_info_integer()` | Используется Sugar |
| `get_account_string()` | **НЕТ** - Просто вызывает `account.account_info_string()` | Используется Sugar |

### Что это значит:

**🏗️ Архитектура (3 слоя):**

```
MT5Sugar (ВЫСОКИЙ)     service.get_account_double()  Sugar использует методы Service
MT5Service (СРЕДНИЙ)   account.account_info_double()  Service — это сквозной слой
MT5Account (НИЗКИЙ)    gRPC-вызов к серверу MT5
```

**Для прямого использования MT5Service:**

- **Используйте `get_account_summary()`** - реальное улучшение (1 вызов вместо 14)
- **Пропустите остальные 3 метода** - нет ценности, просто вызывайте MT5Account напрямую

**Для пользователей MT5Sugar:**

- Все методы работают безупречно - слой выполняет свою архитектурную задачу

---

**Слой API:** **СРЕДНИЙ УРОВЕНЬ** - обёртки над MT5Account с нативными типами Python

**Реализация:**

Эти методы реализованы в `src/pymt5/mt5_service.py`, который оборачивает низкоуровневый API `package/MetaRpcMT5/helpers/mt5_account.py`.

**Файлы примеров:**

- `examples/2_service/04_service_demo.py` - исчерпывающий демо-пример всех методов MT5Service, включая информацию о счёте (STEP 2)

## Зачем эти методы существуют

### Реальная ценность: get_account_summary()

**Основная польза** MT5Service для информации о счёте - это `get_account_summary()`:

**Что он делает:**
- Выполняет 5 внутренних RPC-вызовов (1 сводный + 4 отдельных свойства)
- Преобразует protobuf `Timestamp` в Python `datetime`
- Агрегирует 14 полей в один чистый dataclass `AccountSummary`
- Один вызов метода вместо 14 отдельных вызовов `account_info_*()`

**Пример:**
```python
# MT5Service - ОДИН вызов получает всё
summary = await service.get_account_summary()
print(f"Balance: {summary.balance}, Equity: {summary.equity}")
print(f"Leverage: {summary.leverage}, Server time: {summary.server_time}")  # datetime!

# vs MT5Account - нужно 14 отдельных вызовов
balance = await account.account_info_double(account_info_pb2.ACCOUNT_BALANCE)
equity = await account.account_info_double(account_info_pb2.ACCOUNT_EQUITY)
leverage = await account.account_info_integer(account_info_pb2.ACCOUNT_LEVERAGE)
# ... ещё 11 вызовов ...
```

### Остальные методы: Архитектурный слой

`get_account_double()`, `get_account_integer()`, `get_account_string()` - это **тонкие обёртки**, служащие архитектурным слоем:

**Зачем они существуют:**
- **MT5Sugar (высокий уровень) использует их** - поддерживает слоистую архитектуру (Sugar Service Account)
- **Единый интерфейс** - все методы доступны через один класс
- **Согласованное именование** - префикс `get_*` для всех методов Service
- **Без обработки** - прямая передача в `account.account_info_*()`

**Для конечных пользователей:** Если вы используете MT5Service напрямую (не Sugar), вызов MT5Account идентичен. Эти обёртки не добавляют ценности.

**Для MT5Sugar:** Они необходимы - Sugar должен работать через Service, а не напрямую с Account (слоистая архитектура).

## Все 4 метода

| Метод | Возвращает | Реализация |
|-------|-----------|----------------|
| `get_account_summary()` | dataclass `AccountSummary` | Агрегирует 5 RPC-вызовов + преобразует Timestamp datetime |
| `get_account_double(property_id)` | `float` | `return await self._account.account_info_double(property_id)` |
| `get_account_integer(property_id)` | `int` | `return await self._account.account_info_integer(property_id)` |
| `get_account_string(property_id)` | `str` | `return await self._account.account_info_string(property_id)` |

## ➕ Dataclass AccountSummary (DTO)

```python
@dataclass
class AccountSummary:
    """Complete account information in one convenient structure."""

    login: int                                      # Номер логина счёта
    balance: float                                  # Баланс счёта в валюте депозита
    equity: float                                   # Средства (equity) счёта (баланс + плавающий P&L)
    user_name: str                                  # Имя клиента
    leverage: int                                   # Кредитное плечо счёта (например, 100 для 1:100)
    trade_mode: Any                                 # Торговый режим счёта (demo/real/contest)
    company_name: str                               # Название компании-брокера
    currency: str                                   # Валюта депозита (USD, EUR и т. д.)
    server_time: Optional[datetime]                 # Время сервера (уже datetime!)
    utc_timezone_shift_minutes: int                 # Смещение часового пояса UTC в минутах
    credit: float                                   # Сумма кредита
    margin: float                                   # Маржа, используемая для открытых позиций
    free_margin: float                              # Свободная маржа, доступная для торговли
    margin_level: float                             # Уровень маржи в процентах (средства/маржа * 100)
    profit: float                                   # Текущая плавающая прибыль/убыток
```

**Преимущество:** Все 14 важных свойств в одном dataclass, а `server_time` уже является `datetime` (ручное преобразование не нужно).

## Сигнатуры методов

### 1) get_account_summary

```python
async def get_account_summary(
    self,
    deadline: Optional[datetime] = None,
    cancellation_event: Optional[Any] = None,
) -> AccountSummary
```

**Возвращает всю информацию о счёте** за один вызов (14 полей в одном dataclass).

**Технические детали:** Выполняет 5 внутренних RPC-вызовов:
1. `account_summary()` - получает 11 базовых полей
2-5. `account_info_double()` x 4 - получает margin, free_margin, margin_level, profit

**Результат:** dataclass AccountSummary с 14 полями в нативных типах Python.

**Преимущество:** Один вызов метода вместо 14 отдельных вызовов AccountInfo* (сокращение кода на 93%).

---

### 2) get_account_double

```python
async def get_account_double(
    self,
    property_id: account_info_pb2.AccountInfoDoublePropertyType,
    deadline: Optional[datetime] = None,
    cancellation_event: Optional[Any] = None,
) -> float
```

**Доступные property_id:**

```python
from MetaRpcMT5 import mt5_term_api_account_information_pb2 as account_info_pb2

# Доступные свойства:
ACCOUNT_BALANCE = 0          # Баланс счёта
ACCOUNT_CREDIT = 1           # Кредит
ACCOUNT_PROFIT = 2           # Текущая прибыль/убыток
ACCOUNT_EQUITY = 3           # Средства (equity) (баланс + плавающий P&L)
ACCOUNT_MARGIN = 4           # Используемая маржа
ACCOUNT_MARGIN_FREE = 5      # Свободная маржа
ACCOUNT_MARGIN_LEVEL = 6     # Уровень маржи (%)
ACCOUNT_MARGIN_SO_CALL = 7   # Уровень margin call
ACCOUNT_MARGIN_SO_SO = 8     # Уровень stop out
ACCOUNT_MARGIN_INITIAL = 9   # Начальная маржа
ACCOUNT_MARGIN_MAINTENANCE = 10  # Поддерживающая маржа
ACCOUNT_ASSETS = 11          # Текущие активы
ACCOUNT_LIABILITIES = 12     # Текущие обязательства
ACCOUNT_COMMISSION_BLOCKED = 13  # Заблокированная комиссия
```

**Возвращает:** значение `float` напрямую.

**Технические детали:** Тонкая обёртка над `account.account_info_double()`, который уже возвращает float. Обеспечивает согласованное именование `get_*`.

## 🔗 Примеры использования

### Рекомендуется: get_account_summary() для нескольких свойств

```python
async def display_account_info(service: MT5Service):
    # ЛУЧШИЙ способ — используйте get_account_summary для нескольких свойств
    summary = await service.get_account_summary()

    print(f"Account: {summary.login}")
    print(f"Balance: ${summary.balance:.2f} {summary.currency}")
    print(f"Equity: ${summary.equity:.2f}")
    print(f"Floating P/L: ${summary.profit:.2f}")
    print(f"Margin: ${summary.margin:.2f}")
    print(f"Free Margin: ${summary.free_margin:.2f}")
    print(f"Margin Level: {summary.margin_level:.2f}%")
    print(f"Leverage: 1:{summary.leverage}")
    print(f"Broker: {summary.company_name}")

    # server_time уже datetime (преобразование не нужно!)
    if summary.server_time:
        print(f"Server time: {summary.server_time.strftime('%Y-%m-%d %H:%M:%S')}")
```

### Построение дашборда

```python
async def display_dashboard(service: MT5Service):
    """Display comprehensive account dashboard."""

    summary = await service.get_account_summary()

    print("=" * 60)
    print(f"{'ACCOUNT DASHBOARD':^60}")
    print("=" * 60)

    # Информация о счёте
    print(f"\nAccount Information:")
    print(f"   Login:          {summary.login}")
    print(f"   Name:           {summary.user_name}")
    print(f"   Broker:         {summary.company_name}")
    print(f"   Currency:       {summary.currency}")
    print(f"   Leverage:       1:{summary.leverage}")

    # Финансовое состояние
    print(f"\nFinancial Status:")
    print(f"   Balance:        ${summary.balance:,.2f}")
    print(f"   Equity:         ${summary.equity:,.2f}")
    print(f"   Floating P/L:   ${summary.profit:+,.2f}")
    print(f"   Credit:         ${summary.credit:,.2f}")

    # Состояние маржи
    print(f"\nMargin Status:")
    print(f"   Used Margin:    ${summary.margin:,.2f}")
    print(f"   Free Margin:    ${summary.free_margin:,.2f}")
    print(f"   Margin Level:   {summary.margin_level:.2f}%")

    # Предупреждение, если уровень маржи низкий
    if summary.margin_level < 100 and summary.margin > 0:
        print(f"\nWARNING: Low margin level!")

    print("=" * 60)
```

## Краткий справочник

**Для нескольких свойств счёта:** Используйте `get_account_summary()`
```python
summary = await service.get_account_summary()  # Получает все 14 полей за один вызов
```

**Для одного свойства (редкий случай):** Используйте `get_account_double/integer/string()` или вызывайте MT5Account напрямую
```python
# Оба варианта идентичны:
balance = await service.get_account_double(account_info_pb2.ACCOUNT_BALANCE)
balance = await account.account_info_double(account_info_pb2.ACCOUNT_BALANCE)
```
