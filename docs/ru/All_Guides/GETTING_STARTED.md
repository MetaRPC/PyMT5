# Начало работы с PyMT5

> **Быстрая настройка и обзор** — начните автоматизировать свою торговлю с PyMT5 (Python для MetaTrader 5) за считанные минуты.

---

## 🎯 Что такое PyMT5?

**PyMT5** — это промышленного уровня, типобезопасная клиентская библиотека на Python для взаимодействия с терминалами **MetaTrader 5** через высокопроизводительный **gRPC**. Она избавляет от сложных обёрток C++ DLL и обеспечивает прямую, надёжную программную торговлю.

### 🌟 Ключевые преимущества

-  **Высокая пропускная способность**: нативный стриминг gRPC для субмиллисекундных ценовых тиков и исполнения сделок.
-  **Трёхслойная архитектура**: низкоуровневый gRPC (`MT5Account`), типизированные методы-обёртки (`MT5Service`) и высокоуровневые удобства (`MT5Sugar`).
-  **Устойчивое соединение**: автоматическое переподключение, экспоненциальная задержка и прозрачное восстановление канала.
-  **Полное покрытие**: полный API терминала MT5 — счёт, рыночные данные, торговля и стриминг в реальном времени — на всех трёх слоях.

## 🔑 API-ключ и аутентификация

Для подключения к продакшн-эндпоинтам MetaRPC (`mt5.mrpc.pro:443`) требуется API-ключ:

1. **Регистрация**: создайте аккаунт бесплатно на [https://mrpc.pro/signup](https://mrpc.pro/signup).
2. **Генерация API-ключа**: в панели управления портала MetaRPC по адресу [https://mrpc.pro/my](https://mrpc.pro/my) перейдите в раздел **API Keys**, чтобы сгенерировать и скопировать ваш персональный API-токен.
3. **Настройка соединения**: передайте ваш API-ключ / токен вместе с адресом сервера (`mt5.mrpc.pro:443`) в настройках подключения.

---

## 🆔 Автоматический ID счёта и аутентификация

Эндпоинты MetaRPC требуют аутентификации и управления сессией:

1. **`APIKey`**: ваш персональный токен аутентификации из [https://mrpc.pro/my](https://mrpc.pro/my) (получается при регистрации на [https://mrpc.pro/signup](https://mrpc.pro/signup)). Передаётся в заголовке `APIKey`.
2. **`id`**: GUID сессии терминала, возвращаемый `Connect` / `ConnectEx` (`terminalInstanceGuid`).

> 💡 **Бесшовная автоматизация**: вам не нужно вызывать `GetId` или передавать заголовок `id` при подключении. Сервер автоматически генерирует GUID сессии при подключении и возвращает его вызывающей стороне. SDK автоматически захватывает этот ID сессии и прикрепляет его вместе с вашим `APIKey` ко всем последующим запросам и подпискам на стриминг.

## 🔌 Минимальный пример подключения

Вот как легко инициализировать `MT5Account`, подключиться к вашему терминалу MetaTrader и получить баланс счёта:

```python
account = MT5Account(user=user, password=password, grpc_server=grpc_server)
await account.connect_by_server_name(server_name, base_chart_symbol="EURUSD", timeout_seconds=30)
summary = await account.account_summary()
print(f"Balance: {summary.account_balance}, Equity: {summary.account_equity}")
```
