## tick_value_with_size — Как это работает

---

## 📌 Обзор

Этот пример показывает, как использовать низкоуровневый асинхронный метод `tick_value_with_size()` для получения **стоимости тика и размера тика инструмента** и использования этих данных для **расчёта допустимой дистанции стоп-лосса** при заданном максимальном убытке.

Метод используется как источник рыночных параметров инструмента, а все расчёты рисков выполняются на стороне пользовательского кода.

---

## Сигнатура метода

```python
async def tick_value_with_size(
    symbols: list[str],
    deadline: Optional[datetime] = None,
    cancellation_event: Optional[asyncio.Event] = None,
):
```

Ключевые моменты:

* метод асинхронный и вызывается с `await`
* принимает список символов (даже если нужен только один)
* возвращает параметры стоимости тика и размера тика
* не выполняет никаких расчётов рисков или SL

---

## 🧩 Пример кода — Расчёт дистанции стоп-лосса

```python
async def calculate_sl_distance(
    account: MT5Account,
    symbol: str,
    lots: float,
    max_loss: float
) -> float:
    """Calculate maximum SL distance for given max loss"""

    data = await account.tick_value_with_size(symbols=[symbol])

    if not data.symbol_tick_size_infos:
        raise ValueError(f"Symbol {symbol} not found")

    info = data.symbol_tick_size_infos[0]

    # Вычислить допустимое количество пунктов
    profit_per_pip = info.TradeTickValue * 10 * lots
    max_pips = max_loss / profit_per_pip if profit_per_pip > 0 else 0

    print(f"\nStop Loss Calculation for {symbol}:")
    print(f"  Volume: {lots} lots")
    print(f"  Max Loss: ${max_loss:.2f}")
    print(f"  Profit per pip: ${profit_per_pip:.2f}")
    print(f"  Max SL distance: {max_pips:.1f} pips")

    return max_pips
```

Этот пример демонстрирует полный расчёт параметров стоп-лосса на уровне пользователя на основе рыночных данных.

---

## 🟢 Подробное объяснение

---

### 1️⃣ Получение тиковых параметров инструмента

```python
data = await account.tick_value_with_size(symbols=[symbol])
```

На этом шаге:

* выполняется один асинхронный запрос
* сервер возвращает параметры инструмента
* данные приходят в виде списка `symbol_tick_size_infos`

Метод не знает, как эти значения будут использоваться.

---

### 2️⃣ Проверка наличия данных по символу

```python
if not data.symbol_tick_size_infos:
    raise ValueError(f"Symbol {symbol} not found")
```

Это защита на уровне пользователя:

* проверяется, вернул ли сервер данные
* расчёт останавливается, если данные отсутствуют

---

### 3️⃣ Извлечение данных символа

```python
info = data.symbol_tick_size_infos[0]
```

Каждый элемент содержит:

* `TradeTickValue` — стоимость одного тика
* размер тика и параметры контракта

Пользователь выбирает, какие поля использовать.

---

### 4️⃣ Расчёт стоимости пункта

```python
profit_per_pip = info.TradeTickValue * 10 * lots
```

Здесь начинается бизнес-логика:

* стоимость тика масштабируется
* учитывается объём позиции в лотах
* используется предположение о размере пункта

API не выполняет этот расчёт.

---

### 5️⃣ Расчёт допустимой дистанции стоп-лосса

```python
max_pips = max_loss / profit_per_pip if profit_per_pip > 0 else 0
```

На этом шаге:

* максимально допустимый убыток переводится в пункты
* добавляется защита от деления на ноль

Это целиком решение на уровне пользователя.

---

### 6️⃣ Вывод и возврат результата

```python
return max_pips
```

Функция возвращает уже интерпретированное значение, готовое к использованию в торговых решениях.

---

## Роль низкоуровневого метода

Чёткая граница ответственности:

**`tick_value_with_size()`**:

* возвращает параметры стоимости и размера тика
* не знает объём позиции
* не знает допустимый риск
* не рассчитывает стоп-лосс

**Пользовательский код**:

* задаёт объём и риск
* выполняет все расчёты
* принимает торговые решения

---

## Итог

Этот пример иллюстрирует базовый паттерн работы с рисками:

> **получить рыночные параметры → рассчитать риск → определить торговые уровни**

Метод `tick_value_with_size()` предоставляет исходные данные, а вся логика управления рисками реализуется на стороне пользователя.
