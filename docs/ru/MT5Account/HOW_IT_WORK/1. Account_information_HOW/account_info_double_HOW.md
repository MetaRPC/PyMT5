## account_info_double — Как это работает

---

## 📌 Обзор

Этот пример показывает, как получить **конкретное числовое свойство счёта** с помощью низкоуровневого асинхронного метода `account_info_double()`.

Метод предназначен для запроса **ровно одного значения счёта**, хранящегося в виде числа с плавающей точкой (например, баланс, средства (equity), уровень маржи).

Он выполняет **один запрос** и возвращает **одно значение типа `float`**.

Метод не выполняет никакой агрегации, валидации или торговой логики.

Проще говоря:

> Метод просто запрашивает *«дай мне это числовое свойство счёта»*
> и возвращает результат как обычный Python `float`.

---

## Сигнатура метода

```python
async def account_info_double(
    property_id: AccountInfoDoublePropertyType,
    deadline: Optional[datetime] = None,
    cancellation_event: Optional[asyncio.Event] = None,
) -> float
```

**Ключевые моменты:**

* Метод **асинхронный** и должен вызываться с `await`.
* `property_id` указывает, **какое свойство счёта** запрашивать.
* `deadline` и `cancellation_event` управляют **временем выполнения вызова**.
* Возвращаемое значение — **обычный Python `float`**.

---

## 🧩 Пример кода — Проверка уровня маржи перед торговлей

```python
async def check_margin_level(account: MT5Account, min_level: float = 200.0) -> bool:
    deadline = datetime.now(timezone.utc) + timedelta(seconds=3)

    margin_level = await account.account_info_double(
        property_id=account_info_pb2.AccountInfoDoublePropertyType.ACCOUNT_MARGIN_LEVEL,
        deadline=deadline
    )

    print(f"Margin Level: {margin_level:.2f}%")

    if margin_level < min_level:
        raise ValueError(
            f"Margin level {margin_level:.2f}% is below minimum {min_level:.2f}%"
        )

    return True
```

В этом примере `account_info_double()` используется как **строительный блок** для простой проверки безопасности перед открытием сделок.

## 🟢 Подробное объяснение

---

### 1️⃣ Вызов метода

```python
margin_level = await account.account_info_double(
    property_id=account_info_pb2.AccountInfoDoublePropertyType.ACCOUNT_MARGIN_LEVEL,
    deadline=deadline
)
```

Эта строка выполняет **один запрос** одного числового свойства счёта.

* `ACCOUNT_MARGIN_LEVEL` указывает, **какое значение получить**
* метод асинхронно ожидает ответа терминала
* при успешном выполнении возвращается `float`

На этом этапе:

* валидация не выполняется
* интерпретация значения не происходит
* число возвращается ровно в том виде, в каком его предоставил терминал

---

### 2️⃣ Работа с возвращаемым значением

```python
print(f"Margin Level: {margin_level:.2f}%")
```

Возвращаемое значение — **обычное число Python**.

* нет объектов protobuf
* нет вложенных структур
* не требуется дополнительный разбор данных

Значение можно сразу использовать в вычислениях, логах или условиях.

---

### 3️⃣ Применение бизнес-логики

```python
if margin_level < min_level:
    raise ValueError(...)
```

После получения числового значения начинается **обычная прикладная логика пользователя**.

В этом примере:

* `margin_level` — значение, возвращённое из `account_info_double()`
* `min_level` — порог, определяемый логикой стратегии или управлением рисками

Код просто сравнивает два числа и принимает решение:

* если уровень маржи ниже допустимого — выполнение прерывается
* если условие выполнено — функция завершается успешно

Важно понимать границу ответственности:

* `account_info_double()` **только возвращает число**
* сравнение, интерпретация и реакция на значение **не являются частью API**

Именно так и предполагается использовать низкоуровневые методы — как источник данных, поверх которого строится ваша собственная логика стратегии.

---

## Что делает этот метод

* Запрашивает **одно числовое свойство счёта**
* Выполняет **один асинхронный вызов**
* Возвращает **одно значение типа `float`**

Типичные сценарии использования:

* проверка баланса
* мониторинг средств (equity)
* контроль маржи и свободной маржи
* условия управления рисками

## Итог

* `account_info_double()` — это **низкоуровневый геттер** для числовых свойств счёта.
* Он получает **ровно одно свойство** за вызов.
* Метод возвращает **чистый Python `float`**, готовый к использованию.
* Вся логика принятия решений остаётся на стороне вызывающего кода.
