## symbol_exist — Как это работает

---

## 📌 Обзор

Этот пример демонстрирует, как проверить, **существует ли торговый символ в терминале**, с помощью низкоуровневого асинхронного метода `symbol_exist()`.

Метод используется для базовой валидации входных данных: перед подпиской, перед торговлей или перед загрузкой параметров символа.

Он отвечает только на один вопрос:

> *Известен ли терминалу символ с таким именем?*

---

## Сигнатура метода

```python
async def symbol_exist(
    symbol: str,
    deadline: Optional[datetime] = None,
    cancellation_event: Optional[asyncio.Event] = None,
):
```

Ключевые моменты:

* Метод асинхронный и должен вызываться с `await`
* `symbol` — имя символа в виде строки (например, `"EURUSD"`)
* `deadline` и `cancellation_event` управляют временем выполнения
* Метод возвращает объект с информацией о существовании символа

---

## 🧩 Пример кода — Проверка нескольких символов

```python
async def check_symbols(account: MT5Account, symbols: list[str]):
    results = {}

    for symbol in symbols:
        data = await account.symbol_exist(symbol=symbol)
        results[symbol] = data.exists

    for symbol, exists in results.items():
        status = "[OK]" if exists else "[ERROR]"
        print(f"{status} {symbol}: {'exists' if exists else 'not found'}")

    return results
```

В этом примере `symbol_exist()` используется для последовательной проверки списка символов.

---

## 🟢 Подробное объяснение

---

### 1️⃣ Перебор списка символов

```python
for symbol in symbols:
```

Функция перебирает список строк, где каждая строка — имя торгового символа.

Проверки выполняются **последовательно**, для каждого символа отдельно.

---

### 2️⃣ Проверка существования символа

```python
data = await account.symbol_exist(symbol=symbol)
```

На этом шаге выполняется один асинхронный вызов.

* Имя символа передаётся в метод
* Терминал проверяет, известен ли такой символ
* Результат возвращается в виде объекта ответа

Метод не выбрасывает ошибку, если символ не найден — эта информация возвращается в данных ответа.

---

### 3️⃣ Извлечение результата проверки

```python
results[symbol] = data.exists
```

Объект ответа содержит поле `exists`.

* `True` — символ существует
* `False` — символ не найден

В словарь сохраняется только этот факт, без дополнительной информации о символе.

---

### 4️⃣ Обработка результатов

```python
for symbol, exists in results.items():
```

После завершения всех проверок результаты обрабатываются отдельно.

Это позволяет:

* Сначала собрать данные
* Затем принимать решения или выводить информацию

---

### 5️⃣ Вывод информации

```python
status = "[OK]" if exists else "[ERROR]"
print(f"{status} {symbol}: {'exists' if exists else 'not found'}")
```

Здесь используется обычная прикладная логика:

* Формируется понятный человеку статус
* Выводятся имя символа и результат проверки

Этот код не влияет на саму проверку — он нужен только для удобства.

---

## Итог

В этом примере `symbol_exist()` используется как простой способ проверить корректность имён символов.

Метод вызывается для каждого символа отдельно, возвращает информацию о его существовании, а вся логика обработки результата остаётся на стороне вызывающего кода.
