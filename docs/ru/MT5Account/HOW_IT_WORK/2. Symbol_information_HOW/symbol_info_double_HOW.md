## symbol_info_double — Как это работает

---

## 📌 Обзор

Этот пример демонстрирует, как получить **числовое свойство торгового символа** с помощью низкоуровневого асинхронного метода `symbol_info_double()`.

Метод используется для чтения параметров символа, которые в MetaTrader представлены как числа с плавающей точкой: свопы, спреды, шаг цены, минимальные дистанции и другие торговые характеристики.

Каждый вызов метода запрашивает **одно конкретное числовое свойство одного символа**.

---

## Сигнатура метода

```python
async def symbol_info_double(
    symbol: str,
    property: SymbolInfoDoubleProperty,
    deadline: Optional[datetime] = None,
    cancellation_event: Optional[asyncio.Event] = None,
):
```

Ключевые моменты:

* Метод асинхронный и должен вызываться с `await`
* `symbol` — имя торгового символа (например, `"GBPUSD"`)
* `property` указывает, **какое числовое свойство символа** получить
* `deadline` и `cancellation_event` управляют временем выполнения
* Метод возвращает объект со значением числового свойства

---

## 🧩 Пример кода — Получение ставок свопа для символа

```python
async def get_swap_info(account: MT5Account, symbol: str):
    # Получить своп по длинным позициям
    long_swap_data = await account.symbol_info_double(
        symbol,
        market_info_pb2.SYMBOL_SWAP_LONG
    )

    # Получить своп по коротким позициям
    short_swap_data = await account.symbol_info_double(
        symbol,
        market_info_pb2.SYMBOL_SWAP_SHORT
    )

    print(f"Swap for {symbol}:")
    print(f"  Long: {long_swap_data.value:.2f}")
    print(f"  Short: {short_swap_data.value:.2f}")

    return {
        "long": long_swap_data.value,
        "short": short_swap_data.value
    }
```

В этом примере `symbol_info_double()` используется для получения значений свопа для длинных и коротких позиций по одному символу.

---

## 🟢 Подробное объяснение

---

### 1️⃣ Запрос числового свойства символа

```python
long_swap_data = await account.symbol_info_double(
    symbol,
    market_info_pb2.SYMBOL_SWAP_LONG
)
```

На этом шаге выполняется один асинхронный вызов.

* Имя символа передаётся в метод
* Второй аргумент задаёт тип числового свойства
* Выполняется запрос к терминалу

Результат — объект ответа, содержащий значение свойства.

---

### 2️⃣ Повторный вызов для другого свойства

```python
short_swap_data = await account.symbol_info_double(
    symbol,
    market_info_pb2.SYMBOL_SWAP_SHORT
)
```

Метод вызывается снова, но с другим значением `property`.

Важно:

* Каждый вызов запрашивает **ровно одно свойство**
* Значения не кэшируются
* Каждый параметр извлекается отдельным запросом

---

### 3️⃣ Извлечение числового значения

```python
long_swap_data.value
short_swap_data.value
```

Возвращаемый объект содержит поле `value`.

* В этом поле хранится значение числового свойства
* Тип значения — `float`

После извлечения `.value` можно работать с числом как с обычным значением Python.

---

### 4️⃣ Использование полученных данных

```python
return {
    "long": long_swap_data.value,
    "short": short_swap_data.value
}
```

Полученные значения объединяются в словарь.

Это делается исключительно для удобства вызывающего кода — метод `symbol_info_double()`:

* Не объединяет свойства
* Не интерпретирует значения
* Не знает, как они будут использоваться

---

## Итог

В этом примере `symbol_info_double()` используется как источник числовых параметров торгового символа.

Метод вызывается столько раз, сколько свойств нужно получить, а вся логика обработки и объединения данных выполняется на стороне пользователя.
