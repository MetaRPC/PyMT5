## symbols_total — Как это работает

---

## 📌 Обзор

Этот пример показывает, как использовать низкоуровневый асинхронный метод `symbols_total()` для получения **количества торговых символов** и расчёта на его основе использования «Обзора рынка» (Market Watch).

Метод `symbols_total()` возвращает только числовое значение — общее количество символов. Вся аналитика и интерпретация выполняются на стороне пользовательского кода.

---

## Сигнатура метода

```python
async def symbols_total(
    selected_only: bool,
    deadline: Optional[datetime] = None,
    cancellation_event: Optional[asyncio.Event] = None,
):
```

Ключевые моменты:

* Метод асинхронный и вызывается с `await`
* `selected_only=True` — считать только символы из «Обзора рынка» (Market Watch)
* `selected_only=False` — считать все доступные символы на сервере
* Метод возвращает объект с числовым значением `total`

---

## 🧩 Пример кода — Расчёт использования «Обзора рынка»

```python
async def calculate_mw_usage(account: MT5Account) -> dict:
    all_data = await account.symbols_total(selected_only=False)
    mw_data = await account.symbols_total(selected_only=True)

    total = all_data.total
    used = mw_data.total
    usage_pct = (used / total * 100) if total > 0 else 0

    result = {
        "total_available": total,
        "in_market_watch": used,
        "usage_percent": usage_pct
    }

    print(f"Market Watch Usage:")
    print(f"  Using {used} of {total} symbols ({usage_pct:.1f}%)")

    return result
```

В этом примере метод вызывается дважды с разными параметрами, чтобы сравнить общее количество символов и количество символов, добавленных в «Обзор рынка» (Market Watch).

---

## 🟢 Подробное объяснение

---

### 1️⃣ Получение общего количества символов

```python
all_data = await account.symbols_total(selected_only=False)
```

На этом шаге:

* выполняется один асинхронный вызов
* сервер возвращает количество всех символов, доступных на платформе
* значение доступно в поле `all_data.total`

---

### 2️⃣ Получение количества символов «Обзора рынка»

```python
mw_data = await account.symbols_total(selected_only=True)
```

Здесь метод используется снова, но для другого среза данных:

* считаются только символы, добавленные в «Обзор рынка» (Market Watch)
* результат также возвращается в поле `mw_data.total`

---

### 3️⃣ Извлечение числовых значений

```python
total = all_data.total
used = mw_data.total
```

На этом этапе:

* API больше не используется
* дальше идёт обычная работа с числами в Python

---

### 4️⃣ Расчёт процента использования

```python
usage_pct = (used / total * 100) if total > 0 else 0
```

Пользовательский код:

* защищается от деления на ноль
* вычисляет процент символов, добавленных в «Обзор рынка» (Market Watch)

---

### 5️⃣ Формирование результата

```python
result = {
    "total_available": total,
    "in_market_watch": used,
    "usage_percent": usage_pct
}
```

Метод `symbols_total()` возвращает только число, а структура результата полностью формируется на стороне пользователя.

---

## Роль низкоуровневого метода

Чёткая граница ответственности:

**`symbols_total()`**:

* возвращает количество символов
* не сравнивает значения
* не рассчитывает проценты
* не делает выводов

**`calculate_mw_usage()`**:

* вызывает метод с разными параметрами
* сравнивает результаты
* выполняет вычисления
* формирует статистику

---

## Итог

Этот пример иллюстрирует простой, но важный паттерн работы с низкоуровневым API:

> **получить числовые значения → выполнить расчёт → интерпретировать результат**

Метод `symbols_total()` предоставляет базовые данные, а вся аналитика и выводы остаются на стороне пользовательского кода.
