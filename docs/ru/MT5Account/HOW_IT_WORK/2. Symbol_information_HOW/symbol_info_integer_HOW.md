## symbol_info_integer — Как это работает

---

## 📌 Обзор

Этот пример демонстрирует, как получить **целочисленные свойства торгового символа** с помощью низкоуровневого асинхронного метода `symbol_info_integer()`.

Метод используется для чтения параметров символа, которые в MetaTrader представлены как целые числа: количество знаков после запятой, спред, торговые режимы и другие числовые характеристики.

Каждый вызов метода запрашивает **одно конкретное целочисленное свойство одного символа**.

---

## Сигнатура метода

```python
async def symbol_info_integer(
    symbol: str,
    property: SymbolInfoIntegerProperty,
    deadline: Optional[datetime] = None,
    cancellation_event: Optional[asyncio.Event] = None,
):
```

Ключевые моменты:

* Метод асинхронный и должен вызываться с `await`
* `symbol` — имя торгового символа (например, `"EURUSD"`)
* `property` указывает, **какое целочисленное свойство символа** получить
* `deadline` и `cancellation_event` управляют временем выполнения
* Метод возвращает объект со значением целочисленного свойства

---

## 🧩 Пример кода — Получение Digits и спреда

```python
# Получить digits (количество знаков после запятой)
result = await account.symbol_info_integer(
    symbol="EURUSD",
    property=market_info_pb2.SYMBOL_DIGITS
)
print(f"Digits: {result.value}")

# Получить спред в пунктах
spread_result = await account.symbol_info_integer(
    symbol="EURUSD",
    property=market_info_pb2.SYMBOL_SPREAD
)
print(f"Spread: {spread_result.value} points")
```

В этом примере `symbol_info_integer()` используется для получения параметров, которые напрямую влияют на расчёты цен и торговые условия символа.

---

## 🟢 Подробное объяснение

---

### 1️⃣ Запрос количества знаков после запятой

```python
result = await account.symbol_info_integer(
    symbol="EURUSD",
    property=market_info_pb2.SYMBOL_DIGITS
)
```

На этом шаге выполняется один асинхронный вызов.

* Имя символа передаётся в метод
* Второй аргумент задаёт тип целочисленного свойства (`SYMBOL_DIGITS`)
* Терминал возвращает объект ответа с результатом

Само числовое значение находится в поле `result.value`.

---

### 2️⃣ Использование полученного значения

```python
print(f"Digits: {result.value}")
```

* `result.value` — количество знаков после запятой
* Тип значения — `int`
* Значение можно напрямую использовать в расчётах цен

На этом этапе дополнительных вызовов API не происходит.

---

### 3️⃣ Запрос спреда

```python
spread_result = await account.symbol_info_integer(
    symbol="EURUSD",
    property=market_info_pb2.SYMBOL_SPREAD
)
```

Метод вызывается снова для того же символа, но с другим свойством.

Важно:

* Каждый вызов получает **ровно одно свойство**
* Значения не кэшируются автоматически
* Каждое свойство запрашивается отдельным вызовом

---

### 4️⃣ Работа со значением спреда

```python
print(f"Spread: {spread_result.value} points")
```

* `spread_result.value` — спред в пунктах
* Значение — целое число
* Используется напрямую, без преобразований

---

## Итог

В этом примере `symbol_info_integer()` используется как источник целочисленных параметров торгового символа.

Метод вызывается отдельно для каждого нужного свойства, а вся логика использования полученных значений остаётся на стороне вызывающего кода.
