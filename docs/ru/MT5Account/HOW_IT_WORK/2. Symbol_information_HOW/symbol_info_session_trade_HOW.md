## symbol_info_session_trade — Как это работает

---

## 📌 Обзор

Этот пример показывает, как определить, **разрешена ли торговля по символу в текущий момент**, с помощью низкоуровневого асинхронного метода `symbol_info_session_trade()`.

В отличие от сессий котировок, торговые сессии отвечают на другой вопрос:

> *Можно ли **открывать и закрывать сделки** по этому символу прямо сейчас?*

Это типичная проверка безопасности, используемая перед отправкой ордеров.

---

## Сигнатура метода

```python
async def symbol_info_session_trade(
    symbol: str,
    day_of_week: DayOfWeek,
    session_index: int,
    deadline: Optional[datetime] = None,
    cancellation_event: Optional[asyncio.Event] = None,
):
```

Ключевые моменты:

* Метод асинхронный и вызывается с `await`
* `symbol` — имя торгового символа
* `day_of_week` — день недели, для которого проверяется торговая сессия
* `session_index` — индекс торговой сессии внутри дня (нумерация с `0`)
* Метод возвращает объект со временем начала и окончания торговой сессии

---

## 🧩 Пример кода — Проверка, разрешена ли торговля сейчас

```python
async def is_trading_allowed(account, symbol: str) -> bool:
    now = datetime.now(timezone.utc)

    day_of_week = now.weekday() + 1
    if day_of_week == 7:  # воскресенье
        day_of_week = 0

    try:
        session = await account.symbol_info_session_trade(
            symbol=symbol,
            day_of_week=day_of_week,
            session_index=0
        )

        current_seconds = now.hour * 3600 + now.minute * 60 + now.second

        if getattr(session, "from").seconds <= current_seconds <= session.to.seconds:
            return True
        return False
    except Exception:
        return False
```

В этом примере метод используется для проверки **одной торговой сессии** в текущий момент.

## 🟢 Подробное объяснение

---

### 1️⃣ Определение текущего дня недели

```python
now = datetime.now(timezone.utc)
day_of_week = now.weekday() + 1
if day_of_week == 7:
    day_of_week = 0
```

Здесь подготавливаются данные для вызова API.

* `datetime.weekday()` возвращает число от `0` (понедельник) до `6` (воскресенье)
* Перечисление `DayOfWeek` в MT5 использует:

  * `0` — воскресенье
  * `1` — понедельник
  * …

Код преобразует значение в формат, ожидаемый методом `symbol_info_session_trade()`.

---

### 2️⃣ Запрос торговой сессии

```python
session = await account.symbol_info_session_trade(
    symbol=symbol,
    day_of_week=day_of_week,
    session_index=0
)
```

На этом шаге выполняется один асинхронный вызов.

Метод отвечает на вопрос:

> *Есть ли у этого символа в этот день торговая сессия с индексом 0?*

Если сессия существует:

* возвращается объект со временем начала и окончания торговли

Если сессии не существует:

* сервер возвращает ошибку
* управление переходит в блок `except`

---

### 3️⃣ Преобразование текущего времени в формат API

```python
current_seconds = now.hour * 3600 + now.minute * 60 + now.second
```

Время торговой сессии возвращается как **количество секунд от начала дня**.

Чтобы корректно сравнить текущее время с границами сессии, оно преобразуется в тот же формат.

---

### 4️⃣ Проверка попадания во временной интервал

```python
if getattr(session, "from").seconds <= current_seconds <= session.to.seconds:
    return True
```

Это ключевая проверка в примере.

* если текущее время находится внутри торговой сессии
* торговля считается разрешённой

Если текущее время выходит за пределы интервала — торговля закрыта.

---

### 5️⃣ Обработка отсутствия торговой сессии

```python
except Exception:
    return False
```

Если:

* торговая сессия не существует
* день неторговый
* индекс сессии отсутствует

Функция возвращает `False`.

Отсутствие торговой сессии считается нормальной ситуацией.

---

## Итог

В этом примере `symbol_info_session_trade()` используется для проверки того, разрешена ли торговля по символу в текущий момент.

Метод возвращает временные границы одной торговой сессии, а вся логика определения текущего времени, сравнения и интерпретации результата выполняется на стороне пользовательского кода.
