## symbol_info_string — Как это работает (SYMBOL_PATH)

---

## 📌 Обзор

Этот пример показывает, как использовать низкоуровневый асинхронный метод `symbol_info_string()` для получения строкового свойства символа и его разбора на уровне прикладного кода.

В примере используется свойство `SYMBOL_PATH`, которое описывает расположение символа в иерархии окна «Обзор рынка» (Market Watch) терминала MetaTrader.

---

## Сигнатура метода

```python
async def symbol_info_string(
    symbol: str,
    property: SymbolInfoStringProperty,
    deadline: Optional[datetime] = None,
    cancellation_event: Optional[asyncio.Event] = None,
):
```

Ключевые моменты:

* Метод асинхронный и вызывается с `await`
* `symbol` — имя торгового символа
* `property` указывает, какое строковое свойство символа получить
* Метод возвращает объект, содержащий значение строкового свойства

---

## 🧩 Пример кода — Получение и разбор пути символа

```python
result = await account.symbol_info_string(
    symbol="EURUSD",
    property=market_info_pb2.SYMBOL_PATH
)

path = result.value
folders = path.split("\\")

print(f"Symbol Path: {path}")
print(f"Hierarchy: {' > '.join(folders)}")
```

В этом примере метод `symbol_info_string()` используется для получения пути символа, после чего строка разбирается на отдельные уровни.

---

## 🟢 Подробное объяснение

---

### 1️⃣ Запрос строкового свойства символа

```python
result = await account.symbol_info_string(
    symbol="EURUSD",
    property=market_info_pb2.SYMBOL_PATH
)
```

На этом шаге:

* выполняется один асинхронный вызов
* имя символа и тип строкового свойства передаются в терминал
* возвращается объект ответа

Сам метод не интерпретирует значение — он только возвращает строку, связанную с символом.

---

### 2️⃣ Извлечение значения

```python
path = result.value
```

Здесь:

* `result.value` — обычная строка Python
* пример значения:

```
Forex\\Majors\\EURUSD
```

После этой строки работа с API завершена, дальше используется только локальное значение.

---

### 3️⃣ Разбор строки на уровни

```python
folders = path.split("\\")
```

Разделителем уровней является символ `\\`.

Результат — список строк:

```python
["Forex", "Majors", "EURUSD"]
```

Разбор строки выполняется полностью на стороне пользовательского кода.

---

### 4️⃣ Представление для человека

```python
print(f"Hierarchy: {' > '.join(folders)}")
```

Этот шаг не связан с API.

Он нужен только для:

* визуального отображения иерархии
* отладки
* вывода в интерфейс

---

## Что означает SYMBOL_PATH

`SYMBOL_PATH` — это строковое описание того, **где символ расположен в дереве «Обзор рынка» (Market Watch)** терминала MetaTrader.

Последний элемент пути всегда соответствует самому символу, а все предыдущие элементы — это группы, в которых он отображается.

Например:

```
Forex\\Majors\\EURUSD
```

означает:

> символ `EURUSD` находится в группе `Majors`, которая находится в группе `Forex`

---

## Важное замечание

Структура `SYMBOL_PATH`:

* не стандартизирована
* может различаться у разных брокеров
* может иметь разную глубину

Поэтому путь следует рассматривать как **описательные метаданные**, а не как строгий формат.
